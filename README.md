# Angel Chelsey Waweru - Portfolio

A personal portfolio website showcasing my projects and skills as an aspiring software developer.

## 🌟 Features

- **Responsive Design** - Works seamlessly across desktop, tablet, and mobile devices
- **Modern UI** - Clean, purple-themed design with smooth animations
- **Project Showcase** - Display of completed projects with live demo links
- **Contact Information** - Easy access to email, phone, location, and social profiles

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with Flexbox, Grid, and CSS Custom Properties
- **Responsive Design** - Mobile-first approach with clamp() for fluid typography

## 📦 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Navigate to the project directory:
```bash
cd portfolio2
```

3. Open `index.html` in your browser:
```bash
# Option 1: Double-click index.html
# Option 2: Use a local server
npx serve .
# or
python -m http.server 8000
```

## 🎨 Customization

### Colors
The primary color theme uses `#9D00FF` (purple). To customize, update these CSS variables in `style.css`:
- Primary: `#9D00FF`
- Primary hover: `#7b00cc`
- Background overlay: `rgba(0, 0, 0, 0.3)`

### Content
Edit `index.html` to update:
- Personal information in the header/logo
- About section text
- Project details (titles, descriptions, tech stacks, links)
- Contact information (email, phone, location)
- Social media links

### Background
Replace `background.jpg` with your preferred background image, or remove the `background-image` property in `style.css` body selector.

## 📱 Responsive Breakpoints

The layout adapts automatically using:
- CSS Grid (`auto-fit`, `minmax()`) for project cards
- Flexbox for navigation and social links
- `clamp()` for fluid typography scaling
- Media queries handled implicitly through modern CSS
